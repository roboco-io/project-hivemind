# HIVEMIND Claude Code 진입점

`/hivemind`를 호출할 때마다 MCP 도구 호출 전에 [공통 업무 원본](../../../.agents/skills/hivemind/SKILL.md)을 직접 읽고 그 전체 절차를 따른다. 상대 링크는 이 파일의 디렉터리를 기준으로 해석한다. 원본을 읽을 수 없으면 작업을 중단하고 누락을 알린다. 기억한 절차나 이 진입점으로 원본을 대체하지 않는다.

업무 규칙은 공통 원본에서만 관리한다. 이 파일에는 승인·취소·비용 규칙을 복제하지 않는다. 원본 안의 상대 링크는 원본 디렉터리를 기준으로 읽는다.

연결이나 스킬 탐색에 문제가 있으면 [Claude Code 연결 안내](../../../docs/claude-integration.md)를 읽는다. 이 스킬은 호스트의 도구 권한을 자동 승인하지 않는다.
