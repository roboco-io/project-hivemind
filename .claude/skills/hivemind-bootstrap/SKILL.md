# HIVEMIND 부트스트랩 Claude Code 진입점

`/hivemind-bootstrap`을 호출할 때마다 명령 실행 전에 [공통 업무 원본](../../../.agents/skills/hivemind-bootstrap/SKILL.md)을 직접 읽고 그 전체 절차를 따른다. 상대 링크는 이 파일의 디렉터리를 기준으로 해석한다. 원본을 읽을 수 없으면 작업을 중단하고 누락을 알린다. 기억한 절차나 이 진입점으로 원본을 대체하지 않는다.

업무 규칙은 공통 원본에서만 관리한다. 이 파일에는 실행 순서나 인증 규칙을 복제하지 않는다. 이 스킬은 호스트의 도구 권한을 자동 승인하지 않는다.
