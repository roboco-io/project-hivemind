# ADR 0003: Claude의 같은 세션 내 여러 종료 결과

상태: 구현·원격 수용 통과.

## 관찰

실제 Cloudflare 실행에서 Claude CLI는 코드 변경과 native worker 실행을 마치고
종료 코드 0을 반환했다. 그러나 기존 어댑터는 종료 결과가 한 건이어야 한다는 조건으로
작업을 실패 처리했다. 다음 시험에서 같은 초기 세션에 속한 서로 다른 성공 결과 3건을 확인했다.
각 결과의 UUID는 고유했으며, 마지막 결과가 스트림의 마지막 이벤트였다.
권한 거부는 0건이었다. [구조 진단 기록](../verification/claude-terminal-shape-20261110.json)을 참조한다.

[공식 SDK 문서](https://code.claude.com/docs/en/agent-sdk/sessions)는 init과 result의
`session_id`를 세션 식별에 사용한다. 이번 수정은 관찰한 여러 턴을 같은 세션으로 묶는다.
입출력 방식, CLI 인수와 격리 정책은 유지한다.

## 결정

한 건의 기존 결과 형식은 호환성을 유지한다. 초기 세션 정보가 있으면 결과를 해당 세션에 연결한다.
여러 결과를 수용하려면 다음 조건을 모두 만족해야 한다.

- 초기 세션 UUID가 유효하고 하나의 일관된 루트 세션을 가리킨다.
- 결과는 최대 16건이다. 모든 결과가 같은 루트 세션에 속한다.
- 결과 UUID는 유효하고 서로 다르다. 자식 도구에 귀속된 결과는 거부한다.
- 모든 결과가 성공이며 오류·거부·권한 거부를 포함하지 않는다.
- 마지막 이벤트가 마지막 종료 결과다. CLI는 종료 코드 0으로 끝나고 출력 제한에 걸리지 않는다.

세션 혼합, 중복 식별자, 모호한 초기화, 앞선 실패, 마지막 결과 뒤 이벤트와 초과 건수는 거부한다.
실패 진단에는 고정된 원인 코드와 제한된 구조 정보만 저장한다.

서버는 마지막 출력 snapshot에서 필수 검증을 별도 실행한다.
최종 작업 성공은 필수 검증, 인증 회수와 새 세대 저장, 컨테이너 종료를 확인한 뒤 결정한다.
