# ADR 0003: 워커 pull과 실행 권한, 두 단계 사람 승인

- 상태: 초기 골격에 채택
- 날짜: 2026-11-09

## 배경

워커 연결이 끊겨도 중앙 상태를 유지하고, 중복 실행과 늦은 결과를 구분해야 한다.
사람의 실행 허용과 최종 결과 수락은 서로 다른 판단이다.

## 결정

워커가 승인된 작업을 HTTP로 가져온다. 중앙은 트랜잭션 안에서 선입선출로 claim을 처리한다.
실행마다 runId와 무작위 leaseToken을 만들고, 30초 만료를 5초 heartbeat로 갱신한다.
승인과 결과 수락을 별도로 요구하고 각각의 사유를 이벤트로 저장한다.
워커 역할은 사람의 승인·취소 권한을 갖지 않는다.

## 결과와 대안

중앙에서 워커로 들어가는 연결 없이 할당할 수 있고, 취소·만료 후 결과를 거절할 수 있다.
만료 검사는 요청 시 수행되므로 현재 골격은 실시간 장애 탐지기를 제공하지 않는다.
자동 재시도는 외부 부작용의 중복을 만들 수 있어 지금은 실패로 종료하고 새 작업을 등록한다.
메시지 브로커와 영속 워크플로는 복잡한 복구 요구가 생길 때 검토한다.
