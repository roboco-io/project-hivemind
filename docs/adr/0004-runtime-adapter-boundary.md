# ADR 0004: 실행 제공자와 런타임 분리

- 상태: 계약 채택, 클라우드 구현 보류
- 날짜: 2026-11-09

## 배경

어떤 모델이 작업을 수행하는지와 어떤 컴퓨팅 환경에서 실행하는지는 독립적인 선택이다.
ECS와 Cloudflare Containers는 동일한 API·수명·제약을 제공하지 않는다.

## 결정

AgentAdapter는 AI 실행을 담당하고 RuntimeDriver는 실행 환경의 시작·중지를 담당한다.
실제 원격 실행은 ECS를 먼저 검증하고, Cloudflare Containers는 적합한 경량 작업으로 후속 평가한다.
현재는 mock/local만 허용한다. 타입에 이름이 있다는 이유로 지원하는 것처럼 실행하지 않는다.

## 결과와 대안

모델과 클라우드 조합을 확장할 경계를 확보한다.
대신 런타임별 인증·네트워크·종료 정리와 실제 격리는 별도로 구현하고 검증해야 한다.
하나의 범용 시작 명령으로 두 플랫폼을 취급하는 방식은 채택하지 않는다.
계정·리전·저장소·배포 대상은 사용자 지정 전까지 비워 둔다.
