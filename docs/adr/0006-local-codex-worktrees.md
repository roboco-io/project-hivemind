# ADR 0006: 로컬 Codex 실행과 Git worktree

- 상태: 로컬 실행에 채택
- 날짜: 2026-11-09
- 갱신 범위: [ADR 0004](0004-runtime-adapter-boundary.md)의 mock 전용 범위와 [ADR 0005](0005-evidence-cost-and-diff.md)의 합성 결과 범위를 실제 Codex 실행으로 확장한다. 제공자·런타임 분리와 근거 구분 원칙은 유지한다.

## 배경

모의 워커는 승인과 분배 흐름을 검증하지만 실제 코드 변경과 테스트 근거를 만들지 않는다.
원본 작업 공간의 미커밋 변경을 보존하면서 실제 Codex 실행 결과를 관제실에서 확인해야 한다.

## 결정

설치된 Codex CLI의 비대화형 `exec --json`을 사용한다.
새 SDK 의존성을 추가하지 않고 기존 로그인과 실행 파일을 재사용한다.
연동 옵션은 CLI 0.166.0에서 확인했으며 [공식 CLI 문서](https://learn.chatgpt.com/docs/cli/reference)를 기준으로 한다.

운영자는 서버·워커에 저장소 루트와 테스트 argv를 설정한다.
서버가 시작할 때 고정한 HEAD에서 실행별 detached worktree를 만든다.
등록 당시 테스트 argv를 작업에 복사해 고정한다. 설정 변경이나 재시작으로 기존 작업의 명령을 바꾸지 않는다.
작업 API에는 저장소 ID·base commit·테스트 프로필만 전달한다.
명령은 shell 문자열 대신 argv로 실행한다.

Codex에 workspace-write와 비대화형 승인 정책을 적용하고 사용자 설정을 로드하지 않는다.
관제 토큰을 자식 프로세스에 전달하지 않으며 테스트에는 Codex 인증을 제공하지 않는다.
준비·테스트는 정리된 환경으로 호스트에서 실행한다. 신뢰하는 저장소가 전제다.
worktree는 보안 컨테이너가 아니며 Git 메타데이터를 원본과 공유한다.

실제 diff는 별도 Git index에서 base와 비교해 새 파일·삭제·바이너리를 포함한다.
준비·테스트 종료 코드와 출력, Codex 상태와 제공된 토큰 사용량을 저장한다.
알 수 없는 Codex 금액은 null이다. 실패와 시간 초과를 성공으로 표시하지 않는다.
실행 결과의 저장소·base·테스트 argv와 성공 상태의 일관성을 중앙에서 검사한다.

## 결과와 대안

작업별 변경을 원본 dirty 파일·index와 분리하고 실제 실행 근거를 남길 수 있다.
결과 수락은 적용·커밋·병합·푸시를 수행하지 않는다.
worktree는 검토용으로 보존한다. 변경이 남은 worktree의 삭제는 Git이 거절하며 사용자가 따로 정리한다.

출력은 크기를 제한해 저장하고 잘림을 표시한다. 전체 파일은 보존된 worktree에서 조사한다.
테스트 설정은 실행 중 변경하지 않는다. 서버 재시작 후에도 기존 작업의 base commit은 유지한다.
실행 근거는 인증된 워커의 보고이며 독립 attestation은 아니다.

SDK나 App Server는 지속 대화·도구 승인·상세 이벤트 제어가 필요할 때 평가한다.
실제 보안 격리, 원격 인증과 자원 정리는 ECS 등 후속 런타임에서 구현한다.
