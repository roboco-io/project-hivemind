# ADR 0005: 비용과 변경 제안의 근거 구분

- 상태: 초기 골격에 채택
- 날짜: 2026-11-09

## 배경

사람이 결과를 판단하려면 비용과 변경 내용을 실행에 연결해야 한다.
모의 결과를 실제 저장소 변경이나 확정 과금으로 표시하면 검토 근거를 오해할 수 있다.

## 결정

비용은 USD micros 정수로 저장한다. 예상과 보고 비용을 분리하고, 예산 초과 보고도 보존한다.
초기 골격의 diff는 합성 patch 문자열이며 실제 파일에 적용하지 않는다.
UI와 README에 모의 실행임을 표시한다. 결과 수락은 수락 기록만 남긴다.

## 결과와 대안

로컬 승인 흐름을 외부 지출이나 저장소 변경 없이 검증할 수 있다.
현재 actualCostMicros는 모의 워커 보고액이다. 외부 과금의 확정값이나 하드 한도가 아니다.
실제 실행 도입 전 사용량 원본·가격표 버전·비용 확정 상태와 base/head commit·patch 해시를 추가한다.
실패·취소된 실제 실행도 비용을 누락하지 않는 정산 경로가 필요하다.
