# ADR 0001: 독립 중앙 관제 시스템

- 상태: 채택
- 날짜: 2026-11-09

## 배경

사람은 여러 AI 도구와 원격 워커를 함께 사용한다.
특정 대화 도구의 세션을 전체 작업 상태로 사용하면 다른 도구에서 일관된 관제가 어렵다.

## 결정

작업·실행·승인·비용·이벤트를 독립 중앙 API에 저장한다.
Web UI는 관제 화면이고, Claude Code·Codex·ChatGPT는 같은 API를 사용하는 연결 인터페이스다.
중앙 기획 모델은 교체할 수 있게 둔다. 현재 기획은 사람이 입력한 작업 지시다.

## 결과와 대안

특정 제공자와 무관하게 상태와 승인 정책을 유지할 수 있다.
대신 중앙 저장소, 인증과 장애 복구를 직접 구현해야 한다.
단일 AI 앱 안에만 관제 화면과 상태를 두는 방식은 다중 도구 요구에 맞지 않아 선택하지 않았다.
