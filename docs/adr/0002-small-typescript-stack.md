# ADR 0002: 작은 TypeScript 실행 골격

- 상태: 초기 골격에 채택
- 날짜: 2026-11-09

## 배경

먼저 검증할 것은 사람 승인, 중앙 작업 분배와 별도 워커의 연결이다.
대화에서 제안한 Next.js·PostgreSQL·Temporal 전체를 시작부터 운영하면 설치와 복구 범위가 커진다.

## 결정

Node.js 24 이상, TypeScript, Fastify, 내장 SQLite와 정적 HTML/CSS/JavaScript UI를 사용한다.
단일 패키지 설정 아래 apps와 packages로 책임을 나눈다.
UI는 중앙 상태를 2초마다 조회한다. 현재 SQLite 스키마는 버전 1이다.
검증에 사용한 Node.js 24.14.0은 `node:sqlite`를 실험적 기능으로 표시한다.
이 골격의 로컬 저장소에 한정해 사용하며, 운영 전환 시 지원 상태와 저장소 선택을 재검토한다.

## 결과와 대안

외부 데이터베이스 없이 API와 워커 두 프로세스로 흐름을 재현할 수 있다.
SQLite 동기 접근과 전체 상태 조회는 작은 로컬 검증을 위한 선택이다.
다중 API 인스턴스와 운영 규모가 필요해지면 PostgreSQL, 영속 워크플로와 이벤트 스트리밍을 평가한다.
복잡한 제품 화면이 필요해지면 React/Next.js를 도입한다.
