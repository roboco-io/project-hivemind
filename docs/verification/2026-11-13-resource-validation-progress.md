# 로컬 자원 제약 실측: 실행 준비와 첫 관측

후속 결과: [2026-11-14 A 실측 완료 및 B 인증 문제](2026-11-14-resource-validation.md). 아래 내용은 당시 진행 기록이다.

[실측 계획](../plans/local-resource-validation/measurement-plan.md)을 진행 중이다. 전체 결과가 아니다. 2026-11-14 사용자가 인프라 추정 $10 중단 기준과 두 구독의 초과 과금 꺼짐을 확인했다. 전체 원격 실험 실행이 승인되었다. AWS는 이번 범위에서 실행하지 않는다.

## 구현한 실행 경로

- A: 중앙 compute group에서 독립 검사 4개를 동시성 1·2·4로 실행하고 전체 회귀 검사를 수행한다. 작업과 컨테이너 종료를 확인한 뒤 완료한다.
- B: 공통 계약과 허용 쓰기 경로를 고정한다. Codex는 게시글, Claude는 댓글 기능을 담당한다. 독립 수용 검사 결과를 같은 모델 세션에 전달하는 랄프 루프를 사용한다. 로컬 설정은 원격과 같은 최대 3회다.
- C: 조회용 자식 프로세스를 종료하고 5분 뒤 새 조회 프로세스로 같은 워크플로를 확인한다. 사용자 머신 전체 네트워크를 변경하지 않는다.
- 호스트 계측과 재개 기록, 고정 입력 snapshot, 테스트 개수 검증을 추가했다. 원격 작업 ID는 `hvm-bench-job` 비용 라벨과 연결된다.

실행 도구는 `cloudflare/backend/scripts/resource-validation/`에 있다. fixture는 `cloudflare/backend/benchmark/resource-validation/`에 있다. 배포와 실제 원격 검증은 아직 수행하지 않았다.

## 해석의 한계

이 작은 작업은 현재 머신의 자원 제약을 드러내지 않았다. 한 번의 결과나 더 낮은 응답 시간을 성능 개선으로 해석하지 않는다. 기준 계측 중에도 호스트 CPU 부하가 있었으며, 기존 스왑 약 21 GB는 이번 작업이 만든 값이 아니다.

RSS는 표본이며 공유 페이지가 중복 계산될 수 있다. 네트워크 바이트는 다른 앱의 통신을 포함한다. `memory_pressure -Q`의 가용률은 운영체제의 경고·위험 상태가 아니다. 현재 CPU 표본은 정확한 누적 CPU초를 대신하지 않는다.

B의 로컬 Claude 파일 도구와 원격 Bash/Agent 도구는 다르다. CLI 버전 일치도 본실험 전에 확인해야 한다. 이 차이가 남으면 B는 운영 전체의 비교이며 머신 자원만의 인과 효과로 결론내릴 수 없다. 요청한 모델과 제공자 응답에서 실제 관측한 모델을 구분하며, 관측하지 못한 모델·사용량은 미확인으로 표시한다.

## 남은 실행

A 17개 조건, B 9개 목표, C 3개 목표와 비용·통합 납기 비교가 남았다. 예산 확인 후 배포 사전 검증을 거쳐 고정 순서로 재개한다. 전체 계획의 성공이나 HIVEMIND의 성능 우위는 아직 판정하지 않았다.

## 2026-11-14 원격 사전 실행에서 발견한 결함

첫 Cloudflare 동시성 2 묶음은 2초 주기 조회 중 큐에 머물렀다. 조회를 중단하자 샤드 4개와 전체 회귀 검사가 통과했다. 조회 요청마다 실행 알람을 현재 시각의 2초 뒤로 다시 예약하는 것이 원인이다. 기존의 더 이른 알람을 유지하도록 수정하고 반복 조회·만기 알람·다음 틱 예약 회귀 테스트를 추가했다. 백엔드 186개 테스트와 타입 검사가 통과했다.

이 실행은 사전 검증으로 분리한다. 원격 모든 검사에서 소스 불변·인증 부재, capability 제거와 no-new-privileges가 확인됐다. 원자료는 `.hivemind/resource-validation/cloud-preflight.json`이다. 수정 배포 후 `run-a-v2`에서 같은 snapshot과 순서로 18개 조건을 새로 실행한다. 로컬 비교 CLI는 원격과 같은 Codex 0.166.0·Claude Code 2.1.319로 별도 설치했다.
