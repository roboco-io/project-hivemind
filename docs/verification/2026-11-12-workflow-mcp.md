Codex CLI에서 등록 응답은 `DRAFT`, 별도 승인 응답은 `RUNNING`이었다. 두 워커 모두 첫 라운드 검사에 실패한 뒤 두 번째 라운드 검사에 성공했다. 통합 결과는 `SUCCEEDED`였다. 실제 Git diff는 `add.mjs`와 `multiply.mjs`만 변경했다. 로그에 **통합 테스트 5개 통과·실패 0개**, 종료 코드 0, 출력 잘림 없음이 기록됐다.

검증용 중앙 서비스를 종료한 뒤 같은 SQLite 파일과 설정으로 다시 시작했다. 같은 ID와 통합 결과를 다시 읽었다. 자동 검사에서는 워커 토큰 거부, 계약 경로와 쓰기 범위 검증, 다른 계약 해시의 승인 거부, 서비스 및 MCP 재연결 뒤 중복 등록 방지를 확인했다. `npm run check`는 테스트 149개 통과, 실패 0개였다.
