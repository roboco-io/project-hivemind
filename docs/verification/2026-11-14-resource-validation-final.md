## 비용

사전 검증·문제 진단·중단한 시도까지 포함한 **103개 원격 컨테이너 작업**의 Analytics 사용량을 확인했다. CPU·할당 메모리·디스크·ICN 전송의 소매 환산 합계는 **$0.16047**다. 최종 B의 완주당 중앙값은 원격 순차 **$0.00554**, 원격 병렬 **$0.00561**이며 C는 **$0.00601**이다.

이는 무료 포함량 차감 전 [공식 요율](https://developers.cloudflare.com/containers/platform/pricing/) 환산이다. 최종 청구액이 아니며 R2·Worker·Durable Object·이미지 저장 비용은 제외했다. 로컬 전력·장비 비용도 측정하지 않았다. $10 중단 기준은 별도의 보수적 실행 시간 추정과 예비비로 관리했다.

모델은 사용자가 확인한 구독 및 초과 과금 꺼짐 조건을 사용했다. Claude `modelUsage.costUSD`는 제공자 보고 사용량의 비용 지표이며 구독에 추가 청구된 금액으로 합산하지 않는다. 토큰·캐시 읽기·쓰기와 모델별 사용량은 근거 JSON에 보존했다. 제공자 마지막 result의 보고 범위를 세션 전체 합계로 임의 확대하지 않는다.

## 해결한 문제와 제외한 시도

[진행·진단 기록](2026-11-14-resource-validation.md)에 원자료 위치를 남겼다.

1. 조회 때마다 dispatch 알람을 뒤로 미루던 결함을 수정했다. 더 이른 알람을 유지하고 회귀 테스트를 추가했다. 사전 실행은 A 본표본과 분리했다.
2. 로컬 실행기의 USER 누락으로 갱신된 Keychain 인증을 찾지 못하던 문제를 수정했다. 운영체제 사용자 이름만 전달하며 API 키 등은 계속 제외했다. 이전 로컬 실패 두 건과 Codex 성공 결과를 보존했다.
3. 모델에게 직접 npm 검증을 요구한 지시가 원격 Claude 도구 sandbox와 충돌했다. 이전 조건의 로컬·원격 순차 성공과 원격 병렬 중단을 별도 보존했다. 최종 비교는 양쪽 지시를 소스 수정으로 통일했다. sandbox를 완화하지 않았다.
4. Claude의 제공자 보고 실행 시간·API 시간·턴 수·모델별 숫자 사용량을 안전하게 보존하도록 추가했다. 자유텍스트와 인증 원문은 공개 근거에 넣지 않았다.

## 선택 기준과 남은 한계

**이번 과제는 로컬 실행이 적합하다.** 현재 머신이 감당할 수 있는 병렬도를 이미 사용하므로 작은 작업을 원격으로 옮기는 것만으로 빨라지지 않는다. 승인 후 관제 연결을 유지할 수 없는 경우에는 원격 지속성과 결과 보존이 확인된 HIVEMIND를 선택할 근거가 있다.

로컬 자원 부족을 실제로 유발·해소했다는 증거는 부족하다. 기준 계측에도 다른 앱의 CPU 부하가 있었고, 기존 스왑을 실험의 새 사용량으로 해석할 수 없다. 호스트 네트워크 값에는 다른 앱의 통신이 포함된다. RSS는 표본이며 공유 페이지가 중복 계산될 수 있다. 가용 메모리 비율은 운영체제의 메모리 압박 등급이 아니다.

B의 로컬 Claude 파일 도구와 원격 Bash/Agent 구성이 다르므로 환경 자원만의 인과 효과로 해석하지 않는다. 첫 토큰 시간·HTTP 모델 요청 수·로컬 정확한 누적 CPU초는 이번 계측으로 확보하지 못했다. CLI 턴 수를 HTTP 요청 수로 바꾸어 쓰지 않는다. 계획에 없던 사람의 진단 시간도 자동 실행 납기 표와 별도로 고려해야 한다.

다음 단계는 현실적인 더 큰 저장소에서 로컬 동시성 1·2·4의 처리량 한계를 먼저 찾는 것이다. 실제 빌드·테스트 부하가 32 GiB 머신의 메모리·응답성 한계를 넘는 지점을 확보한 뒤 같은 범위의 원격 완료율·납기·비용을 비교해야 한다. 고정 4 MiB snapshot 안의 작은 앱 결과를 대규모 개발로 일반화하지 않는다. AWS는 아직 진행하지 않았다.
