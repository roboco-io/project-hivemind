# DuckDB 빌드 본실험

입력 복원은 워커별 시간 합계, 빌드는 컴파일·링크 구간의 시간 합집합이다. 로컬 메모리는 작업 트리 RSS 표본, 원격은 단일 워커의 최대 cgroup 메모리다. 로컬 CPU는 명령별 wait4 합계, 원격 CPU는 네 워커의 cgroup 합계다. 원격 통합은 결과 수집과 최종 집계 작업이며 로컬은 별도 통합 작업을 실행하지 않는다.
