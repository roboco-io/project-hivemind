# 로컬 자원 계측 사전 측정

[로컬 자원 제약 검증](../plans/local-resource-validation/experiment.md)의 첫 기준선을 측정했다. MacBookPro18,3, 논리 CPU 10개, 메모리 32 GiB에서 고정 커밋 `d3340da`를 임시 디렉터리에 풀고 기존에 설치된 의존성을 사용했다. 모델 호출 없이 `npm run check`를 1회 실행했다.

| 관측값 | 결과 |
|---|---:|
| 빌드·검사 완료 시간 | 15.02초 |
| 명령 CPU 시간 · user + sys | 25.93 CPU초 |
| `time -l`의 최대 RSS | 약 467 MiB |
| 테스트 | 149개 통과 |
| 짧은 Node 명령 p95 · 작업 시작 전 30회 | 47.0 ms |
| 짧은 Node 명령 p95 · 작업 중 65회 | 53.8 ms |

짧은 명령은 새 Node 프로세스에서 `Math.sqrt(2)`를 계산한다. 프로세스 시작부터 종료까지 측정하므로 사용자 머신 응답성을 추적하는 한 가지 지표다. RSS는 `time -l`이 보고한 값이다. 동시 하위 프로세스의 전체 메모리 피크, 유휴 상태의 장시간 변동, 스왑 및 네트워크는 추가 계측이 필요하다.

이번 한 건은 계측이 작동한다는 근거다. CPU 부하가 커졌을 때의 응답성과 동시 완주 한계는 다음 반복 비교에서 측정한다.
