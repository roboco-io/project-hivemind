# INTENT — HIVEMIND 로컬 자원 제약 검증

> status: exploring

## Why

하이브 마인드의 유용성은 로컬 환경사용시의 cpu 와 메모리, 네트워크등의 제약을 해결할 수 있다는 가설에서 출발해.

## What

로컬 머신은 컨트롤 타워로서 작업을 제출·승인하고 결과를 검토한다. Cloudflare 또는 AWS ECS의 워커 클러스터가 개발 작업을 병렬 실행하고 결과를 통합·검증한다. 클라우드 비용을 부담해도 병렬 실행이 대규모 작업의 통합 완료 시간을 충분히 줄이고 로컬 자원 제약을 완화하는 조건을 확인한다.
