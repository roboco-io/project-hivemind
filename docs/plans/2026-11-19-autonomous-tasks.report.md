# 장기 자율 작업 1차 구현 결과

2026-11-19, 이슈 #1의 중앙 정책과 mock 실행 기반을 구현했다. 이슈 전체를 완료한 것은 아니다.

## 구현

- 장기 작업 계약과 중앙 상태 전이, revision에 고정한 승인·재승인.
- 짧은 실행의 claim·heartbeat·절대 실행 기한, 예약 대기와 명시적 재개.
- SQLite 지속성과 Cloudflare Durable Object 저장·HTTP 경로. 운영자와 워커 권한을 분리했다.
- 작업별 주 모델·서브에이전트 모델, 비공개 체크포인트와 사용량 계약.
- 외부 행동의 멱등 예약·정산, 비용 대사, 자원 원장과 정리 재시도.
- 사람 개입과 에이전트 도움 요청의 별도 집계.
- 실제 HTTP를 사용하는 `npm run autonomous:mock` 시연.

## 반복 검증과 수정

테스트를 먼저 작성하고 구현·검증·수정을 반복했다. 구성 요소 구현 후 독립 검토에서 다음 결함을 수정하고 회귀 테스트를 추가했다.

- lease 갱신과 절대 실행 기한 혼동, lease 만료 시 비용 누락.
- 설정 변경으로 정리 대기를 우회하거나 저장 상태를 복원할 수 없게 되는 문제.
- 비용 합산 정수 범위 초과와 승인·상태 복원 검증 누락.
- 입력 대기 중 자원 정리 누락, 저장 용량 한도에서 취소 차단.
- 추가 필드 전송, 취소 직후 지연된 행동 실행, 실행 전 오류의 lease 잔류.
- 새 HTTP 경로에서 파서 오류 상세 정보가 반환되는 문제.

## 남은 범위

내장 네이티브 자율 실행기, 영속 비공개 세션 저장소, 실제 AWS·Hugging Face 도구와 자격 증명 연결, 실제 비용 집행·자원 정리, 장기 이력 분할 저장·페이지 조회는 추가 구현이 필요하다. 실제 CLI 세션 복원·캐시 적중과 24시간·8주 운영도 검증하지 않았다.

lease 만료 시 비용을 알 수 없으면 같은 작업을 보존하고 대사를 기다린다. 비용 확인 후 명시적으로 재개한다. 이를 완전한 무인 장애 복구로 간주하지 않는다.

기존 미커밋 변경을 보존했다. 기존 dirty 파일 중 `cloudflare/backend/src/cloudflare/worker.ts`에만 연결 코드를 추가했다. 자동 checkpoint 커밋·외부 푸시·모델 호출·유료 자원 생성·배포는 하지 않았다.

실행법·API·R1–R11별 상태는 [장기 자율 작업 안내](../autonomous-tasks.md)에 기록했다.
