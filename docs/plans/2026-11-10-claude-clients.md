# Claude Code 앱·CLI 등록과 네 접점 검증 계획

사용자 요청: 기존 설정을 보존하며 Claude Code 앱·CLI의 MCP 등록과 스킬을 구현한다. Codex를 포함한 네 접점을 실제 검증한 뒤 커밋·푸시한다. AWS는 진행하지 않는다.

## 구현

1. 프로젝트 `.mcp.json`의 `hivemind`만 관리하는 등록 도구를 만든다. 다른 JSON 값을 보존하고 관리되지 않은 동명 항목은 거부한다. 개인 경로와 복구 자료는 Git에서 제외한다.
2. `.claude/skills/hivemind`는 공통 `.agents/skills/hivemind/SKILL.md`를 매번 읽는다. 별도 업무 규칙이나 권한 자동 승인은 추가하지 않는다.
3. 실제 CLI·앱 세션에서 스킬 발견과 MCP 호출을 확인한다. 기존 두 워커 결과의 diff·테스트 조회를 우선 사용한다. 전체 실행 수용과 조회 검증을 구분한다.
4. 전체 검사와 독립 코드 검토를 수행한다. 사용자 승인이 필요한 앱 접근을 기다리고, 검증 결과를 공개 가능한 문서로 남긴다.

## 보존할 경계

- 전역 설정, 기존 Codex 설정, 제공자 인증 원본을 변경하지 않는다.
- 도구 호출 승인과 원격 실행 승인을 구분한다. 기존 원격 인증 스트림을 사용한다.
- 설정 충돌·동시 변경·중단 시 덮어쓰기를 거부하고 비공개 복구 자료를 보존한다.
- SDK나 워커 성공으로 실제 앱 검증을 대체하지 않는다. 차단된 항목은 미확인으로 남긴다.

## 현재 상태

등록 도구와 스킬 구현, 테스트 148개와 독립 검토, 네 실제 앱·CLI 접점의 상태·결과 조회를 통과했다. 새 원격 작업의 전체 실행 수용은 별도 범위다. [검증 기록](../verification/2026-11-10-claude-clients.md)을 따른다.
