# MVP 범위

## 제품 목표

한 사람이 중앙에서 작업을 등록하고 여러 원격 AI 워커에 분배한다.
사람은 Codex와 Claude Code 각각의 앱·CLI에서 진행 상황, 실패, 승인 대기와 Git 변경을 이해하고 통제한다.
네 접점은 모두 1차 지원 대상이다. 구현·실제 검증 상태와 완료 기준은 [지원 설계](client-support.md)를 따른다.
MCP·스킬을 공통 접점으로 사용하며 웹 화면은 검증·관리 보조 도구다.

## 현재 로컬 실행 범위

| 항목 | 제공하는 행동 |
|---|---|
| 작업 등록과 승인 | 목표·완료 조건·예산을 저장. 실행 승인 전에는 워커가 가져가지 못함 |
| 실행 선택 | 모의·Codex·Claude Code 워커 선택 |
| 저장소 정책 | 운영자가 지정한 저장소·고정 커밋·테스트 프로필만 사용 |
| 작업 공간 | 실행마다 detached worktree 생성. 원본 dirty 파일·index와 구분 |
| 실제 결과 | 추적 파일 변경·삭제·새 파일·바이너리 diff, base/HEAD와 worktree 표시 |
| 테스트 | 준비·테스트 argv, 상태·종료 코드·소요 시간·stdout/stderr 표시 |
| 실패 처리 | 제공자·준비·테스트 실패에도 가능한 diff와 근거 저장. 실패 결과 수락 금지 |
| 실행 권한 | 제공자별 분배, 중복 claim 방지, heartbeat·만료·취소와 프로세스 종료 |
| 비용 | 모의 금액과 두 실제 제공자의 미확정 금액 구분. 제공된 토큰 수만 기록 |
| 이력과 역할 | 재시작 후 상태·승인·실행 근거 유지. 워커가 사람의 결정을 대신 기록하지 못함 |

현재 실행 환경은 `local`이다. worktree는 파일 변경 격리이며 원격 보안 컨테이너가 아니다.
이 로컬 경로는 신뢰하는 저장소를 대상으로 한다. 아래 Cloudflare 원격 경로와 구분한다.
초기 모의 흐름은 [초기 계획](plans/2026-11-09-bootstrap.md),
실제 실행 범위는 [Codex 개발 계획](plans/2026-11-09-codex-worktree.md)과
[Claude 워커 계획](plans/2026-11-09-claude-worker.md)에 정리했다.

## 로컬 실행 수용 시나리오

- 설정이 없는 서버는 모의 실행만 노출한다. 설정된 서버는 저장소·base commit·테스트 명령을 보여 준다.
- 사람이 Codex 또는 Claude 작업을 승인하면 해당 제공자의 워커만 작업을 가져간다.
- 각 제공자의 실행 근거를 구분하고 기존 Codex 기록도 동일하게 조회한다.
- 원본 작업 공간에 변경이 있어도 고정 커밋에서 별도 worktree를 만들고 원본 변경·index를 보존한다.
- UI에서 실제 diff와 테스트 결과를 확인한다. 변경 없는 diff와 미보고 상태를 구분한다.
- 제공자·준비·테스트 실패나 시간 초과를 성공으로 표시하지 않는다. 실패 근거도 조사할 수 있다.
- 취소·실행 권한 만료 뒤 결과가 작업을 덮어쓰지 못한다.
- 재시작 후 승인 대기와 제출된 실행 근거를 복원한다.
- 금액을 모르면 미확정으로 표시한다. 미수집 사용량을 0달러로 확정하지 않는다.
- 결과 수락은 외부 저장소 적용·커밋·병합·푸시나 배포를 수행하지 않는다.

## 현재 Cloudflare·Codex 연결 범위

- Codex 앱·CLI의 MCP 도구와 공통 스킬로 초안·승인·상태·diff·테스트·중단을 조작한다.
- 운영자 전용 중앙 API가 비밀을 보관한다. 브라우저나 MCP가 제공자 인증을 직접 받지 않는다.
- 고정 커밋 worktree와 기존 snapshot client로 작업을 제출하고, 영속 key로 중복·응답 유실을 처리한다.
- native 원격 상태·실제 테스트·Git diff·인증 저장·컨테이너 종료 근거를 표시한다.
- 실패 결과는 수락하지 않는다. 수락은 원본 적용·merge·push가 아니다.
- 실제 Codex·Claude 동시 실행을 웹에서 확인하고 같은 결과를 MCP stdio로 조회했다.

[연결 안내](codex-integration.md)와 [실제 검증](verification/2026-11-10-codex-integration.md)을 참조한다.
프로젝트에 MCP를 등록한 뒤 새 Codex 세션이 필요할 수 있다. 상시 HUD는 제공하지 않는다.
입력 소스 한도는 현재 4MiB·1000파일이다. 검증 환경은 전용 작은 저장소다.

## 현재 MVP에 남은 범위

우선 Claude Code 등록·스킬 어댑터와 네 앱·CLI의 실제 종단 수용이 필요하다.
워커 제공자 지원과 사용자가 조작하는 호스트 지원을 구분한다.

전체 장애·재개 수용, 실제 청구 기반 비용 수집과 도구별 세밀한 승인·이벤트 스트리밍을 확장한다.
자연어 목표 분해와 작업 DAG는 아직 구현하지 않았다.
AWS 백엔드는 현재 MVP가 완전히 끝난 다음 단계에서 AWS CDK로 진행한다.

## 후속 확장

추가 호스트 UI와 상시 HUD,
모델별 비용·능력 라우팅, 작업 의존성 DAG와 다중 사용자 권한을 단계적으로 추가한다.
결제, 마켓플레이스와 공개 서비스 운영은 현재 범위에 포함하지 않는다.
