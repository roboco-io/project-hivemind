# 개발 로드맵

일정과 인프라 비용은 실제 저장소·제공자·리전을 정한 후 산정한다.
현재 구현 범위와 후속 단계를 구분한다. 검증 결과는 해당 테스트·실행 기록에서 확인한다.

| 단계 | 범위 | 완료 조건 |
|---|---|---|
| 0. 로컬 모의 골격 | 중앙 API, SQLite, Web UI, 모의 워커 구현 | 승인→claim→결과→수락. 권한·만료·지속성 검증 |
| 1. 로컬 실제 실행 | Codex·Claude CLI, 공통 Git worktree·diff·테스트 계층 구현 | 고정 커밋 실행, 원본 변경 보존, 실패·취소·시간 제한과 실행 근거 검증 |
| 2. Cloudflare 원격 실행 | Codex·Claude 작업별 컨테이너, 인증 회수, 별도 검증 | 실제 원격 실행과 diff·테스트·컨테이너 종료 근거 확보 |
| 3. MVP 수용과 경제성 비교 | 네 앱·CLI 실행 검증, 실제 저장소 연결, 워커별 랄프 루프 | 남은 앱 실행 검증, 동일 세션의 반복과 종료 조건 검증, 비용·완료 시간·품질 비교 |
| 4. 계획·실행 정책 확장 | 대규모 목표 분해, 작업 의존성과 결과 통합, 모델·런타임 라우팅 | 관측한 병목을 해결하고 사람이 실행 범위와 분할을 승인 |
| 5. 운영과 런타임 확장 | 조직 인증, 이력 조회, 필요 시 PostgreSQL·영속 워크플로·AWS CDK | 장애 복구·권한 격리·이벤트 재생·비용 정산 검증. AWS는 현재 MVP 완료 후 진행 |

## 다음 구현 단위

1. **P0** 두 앱에서 새 작업의 등록·승인·실행·결과를 검증한다. 실제 저장소의 기준 커밋과 입력 한도를 제출 전에 확인한다.
2. **P0** [실험 설계](plans/2026-11-11-context-continuity-experiment.md)에 따라 단일 세션·작업 묶음·독립 세션 분할을 비교한다. 제공자가 보고한 캐시·토큰 원본과 가격표 버전을 보존한다.
   [초기 로컬 실험 결과](verification/2026-11-11-context-continuity.md)를 확보했다. 실제 저장소와 원격 환경에서 반복 비교한다.
3. **P0** 공통 계약을 고정한 두 워커 흐름에서 [랄프 루프와 원격 통합 검증](../cloudflare/backend/README.md#두-워커의-원격-통합-워크플로)을 지원한다. 실제 저장소와 앱·MCP 연결까지 수용 범위를 넓히고, 반복을 포함한 토큰과 완료 시간을 수집한다.
4. **P0** 독립적으로 검증하고 통합할 수 있는 작업의 분산 흐름을 정리한다. 공유 컨텍스트, 의존성, 예상 시간 절감과 추가 비용을 검토해 병렬 실행 범위를 승인한다.
5. **P1** 진행 이벤트·복구·출력 및 patch의 보관과 페이지 조회를 개선한다. 로컬 테스트에 별도 보안 런타임을 검토한다.

운영 설정 변경으로 실행 중 테스트 프로필이 바뀌지 않도록 한다.
서버 재시작은 새 작업의 base snapshot을 갱신하지만 기존 작업의 base commit을 바꾸지 않는다.
현재 재시도는 새 작업 생성이다. 자동 재시도 전에는 시도별 실행 기록과 결과 제출 멱등성을 추가한다.

## 기술 전환 조건

| 전환 후보 | 도입을 검토할 조건 |
|---|---|
| PostgreSQL | 중앙 API 다중 인스턴스, 복잡한 조회와 관리형 백업 필요 |
| 영속 워크플로 엔진 | 장시간 승인 대기, 여러 단계 복구·재시도·보상 필요 |
| SSE / WebSocket | 2초 조회 지연이나 부하가 실제 관제에 문제를 일으킴 |
| 제공자 SDK / App Server | CLI 일회 실행을 넘어 지속 대화·인증·도구 승인 제어 필요 |
| React / Next.js | 제품 화면과 상태 관리가 현재 정적 UI의 범위를 넘음 |
| AWS CDK 실행 백엔드 | 현재 MVP 완료 후 실행 제약·비용·운영 요구가 추가 백엔드를 정당화 |

컨테이너 가격만으로 최저 비용을 판단하지 않는다.
모델 사용량, 재시도, 실행 시간, 네트워크와 운영 부담을 함께 측정한다.
소스와 문서의 라이선스는 Apache-2.0이다.
공개 제품명과 서비스 제공 범위는 제품 출시 전 별도 결정한다.
