# 초기 골격 검증

검증일: 2026-11-09. 아래 기록은 로컬 초기 골격의 검증 결과다.
외부 모델 호출과 클라우드 배포는 수행하지 않았다.
공개 소스 저장소는 [roboco-io/project-hivemind](https://github.com/roboco-io/project-hivemind)다.

## 자동 검증

Node.js 24.14.0에서 `npm run check`를 실행했다.
타입 검사와 빌드 성공, 자동 테스트 17개 통과, 실패·생략 0개.
전달용 압축본을 별도 폴더에 풀고 `npm ci`와 `npm run check`로 설치·검증도 확인했다.
최종 코드 검토에서 발견한 트랜잭션 대기 중 lease 만료 문제를 수정하고 회귀 검증을 추가했다.

- 실행 승인과 결과 수락의 분리, 승인 이벤트와 사유 보존.
- 한 작업의 중복 claim 방지, 잘못된 lease 거절, 만료·취소 뒤 결과 거절.
- 만료 검사 직후 트랜잭션 대기 중 기한이 지나도 heartbeat·결과 제출 거절.
- 미지원 제공자/런타임과 잘못된 입력 거절, 예산 초과 보고액 보존.
- SQLite 재시작 후 상태·diff·비용·승인 복원.
- 운영자/워커 권한 구분, 토큰이 관제 응답에 포함되지 않음.
- 실제 HTTP에서 API와 별도 워커 모듈의 등록→claim→결과→사람 수락.
- 모의 어댑터 취소, heartbeat 거절 뒤 실행 중단, 실패 보고.

## 브라우저 검증

실제 중앙 API와 별도 워커 프로세스를 연결했다.
관제실에서 작업 등록→실행 승인→결과·합성 diff·$0.001000 확인→결과 수락을 수행했다.
수락 후 종료 상태와 승인 입력 숨김을 확인했다.
추가 UI 점검에서 사용자 입력의 HTML 비실행, 조회 중 입력·포커스 유지,
390px 화면에서 가로 넘침 없음을 확인했다.

## 컨테이너 검증

`docker build -t project-hivemind:local .` 성공.
별도 테스트용 Compose 프로젝트에서 중앙 서버와 워커를 실행했다.
생성→승인→컨테이너 워커 결과→수락을 확인하고, 중앙 서버 재시작 후 기록 복원을 확인했다.
컨테이너에서 대시보드 파일이 정상 제공됨을 확인했다.
검증용 컨테이너·네트워크·볼륨은 종료 후 제거했다.

## 검증 범위 밖

실제 Codex·Claude·ChatGPT 연결, 실제 Git diff 수집, ECS/Cloudflare 실행,
다중 사용자 인증, 외부 과금 상한, 장애 내구성과 성능은 검증하지 않았다.
Node 24의 내장 SQLite는 실험적 기능 경고를 표시한다.
이번 결과는 로컬 모의 골격의 동작을 확인한 것이며 운영 배포 준비를 뜻하지 않는다.
